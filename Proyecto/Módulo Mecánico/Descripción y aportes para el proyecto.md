# DESCRIPCIÓN Y APORTES 
## ONSHAPE

## Descripción

Este proyecto fue desarrollado utilizando la plataforma Onshape para el diseño y modelado de piezas mecánicas mediante técnicas de CAD paramétrico. Durante el desarrollo se realizaron diversos bocetos y operaciones de modelado para construir una solución funcional, optimizando dimensiones, restricciones geométricas y relaciones entre componentes.

El trabajo permitió aplicar conocimientos de diseño asistido por computadora, modelado 3D, ensamblajes y documentación técnica, fortaleciendo las competencias en ingeniería y manufactura digital.

## Objetivos

* Diseñar componentes mediante modelado paramétrico.
* Crear bocetos técnicos con restricciones geométricas.
* Construir modelos tridimensionales funcionales.
* Validar dimensiones y relaciones entre piezas.
* Generar documentación técnica del proyecto.

## Aportes al Proyecto

### Diseño de Bocetos

Se desarrollaron bocetos iniciales para definir la geometría base de las piezas, estableciendo dimensiones, restricciones y relaciones necesarias para garantizar la precisión del modelo.

### Modelado 3D

A partir de los bocetos se realizaron operaciones de extrusión, corte y modificación para construir los componentes tridimensionales del proyecto.

### Optimización del Diseño

Se ajustaron dimensiones y parámetros con el fin de mejorar la funcionalidad, estabilidad y facilidad de fabricación de las piezas diseñadas.

### Documentación Técnica

Se elaboró la documentación correspondiente para registrar el proceso de diseño, las decisiones tomadas y las características técnicas del modelo final.
